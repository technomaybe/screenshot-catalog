About This App

Local OCR-powered screenshot search for Windows. Running on port {{ current_port }}.

What it does

  • Indexes screenshot text with OCR into SQLite
  • Searches by words, phrases, domains, and ticket IDs
  • Shows inline thumbnails and full OCR text
  • Builds a word cloud from indexed content

Quick help

  • Use Search to find screenshots by content
  • Use Word Cloud to spot common topics
  • Use Settings to change folders, export defaults, and port
  • Use Re-index after adding new screenshots
